========================================================================================
                 SISTEMA DE PIPELINES MODULAR (NODOS INDEPENDIENTES)
========================================================================================

1. CATÁLOGO DE NODOS (ScraperLab-Nodes):
   Bloques reutilizables disponibles para cualquier pipeline o cliente:
   - [TRIGGER]      -> Captura inputs iniciales del cliente.
   - [SCRAPE_SEARCH]-> Búsquedas en marketplaces (Falabella, Éxito, ML, Alkosto).
   - [SCRAPE_DETAIL]-> Extracción profunda de fichas de producto.
   - [AI_PROMPT]    -> Matchers inteligentes y catalogación con Gemini.
   - [CONDITION]    -> Lógica de decisión: (var > 1) -> [onTrue] / [onFalse].
   - [API_REQUEST]  -> Sincronización con APIs internas (ej: Oferty) o Webhooks.

2. PIPELINES COMO ORQUESTADORES DE RELACIONES (ScraperLab-Pipelines):
   Los pipelines no reimplementan la lógica, solo componen el flujo:

        [start]
           │
           ▼
     [search_engine]  (ref: 'oferty-marketplaces-search')
           │
           ▼
      [ai_matcher]    (ref: 'oferty-gemini-product-matcher')
           │
           ▼
    [evaluar_matches] (ref: 'oferty-condition-has-matches')
           │
     ┌─────┴────────────────┐
     │ ¿matches > 0?        │
     ▼                      ▼
  (TRUE)                 (FALSE)
     │                      │
     ▼                      ▼
[sync_oferty]        [notify_telegram]
(ref: API Patch)     (ref: Bot Telegram)
