Node.js + Express + AWS Lambda + DynamoDB + Cheerio

✅ Arquitectura en Capas:

- handlers/      (Controladores HTTP: validación, respuestas)
- services/      (Lógica de negocio y orquestación)
- repositories/  (Acceso a datos DynamoDB)
- strategies/    (Patrón Strategy: providers y dominios)
- middleware/    (Manejo de errores, CORS, etc)
- utils/         (Funciones reutilizables)

✨ Patrón Strategy:

Cada dominio (Falabella, Éxito, MercadoLibre) tiene su propia estrategia
de extracción que hereda de BaseDomainStrategy. Los providers externos
(ScraperAPI, Oxylabs) también usan el patrón Strategy.

📊 Flujo de Datos:

Handler → Service → Strategy/Repository → Response

🔄 Beneficio:

Separación clara entre:
- Lógica HTTP (handlers)
- Lógica de negocio (services)
- Acceso a datos (repositories)
- Extracción específica por dominio (strategies)
